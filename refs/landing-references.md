# 요고비 랜딩 고도화 · Mobbin 레퍼런스 10선

작성: 2026-09-16 · 출처: [Mobbin](https://mobbin.com) (팀 계정으로 열람)

> **보관 방식 안내.** Mobbin 화면은 저작권 자료라 이미지 자체를 레포에 넣지 않는다.
> 대신 아래에 **바로 여는 링크 + 유사도 + "무엇을 참고할지"** 를 정리해 보관한다.
> 링크를 열면 실제 화면을 볼 수 있고, 필요하면 각자 캡처해 디자인 툴에 붙인다.
> 최상위 매치(1번)는 이번 세션 대화에 캡처를 남겨 두었다.

우리 랜딩의 목표(2차 멘토링 반영): **"통신비·구독료를 얼마나 줄여주는가"를 상대값(절감액)으로 각인**,
판단 부담을 덜어주는 흐름, 절제된 위계. 아래 10선은 이 기준으로 골랐다.

## 최우선 (유사도 ★★★★★ ~ ★★★★)

### 1. Rocket Money — 구독·지출 관리 · ★★★★★  · **캡처 보관됨**
- 위치: Mobbin Web → [Rocket Money](https://mobbin.com/apps/rocket-money-web-0b210b21-3e66-4675-a014-35f09f8bdeae) → Flows › Onboarding
- 왜: 우리와 도메인이 가장 가깝다(구독 절약). 랜딩 히어로가 **"The money app that works for you" + 폰 목업에 `$3,298 · $38 below avg spend`** — 절대 총액이 아니라 **또래 평균 대비 상대값**을 보여준다(멘토 #10과 정확히 일치).
- 참고할 것: 히어로에 절감·평균대비 수치 노출 / "80%가 절약" 같은 증거 프레이밍 + 일러스트 리듬 / 신뢰 칩("Bank-level encryption").

### 2. Wise — 송금 · ★★★★
- 위치: Mobbin Web → "Wise" 검색
- 왜: 랜딩·계산기에서 **"은행보다 X 절약"** 을 전면에 세운다. 상대 비교로 가치를 각인하는 대표 사례.
- 참고할 것: 입력→즉시 절감액 미리보기(우리 온보딩 "여기까지 하면 예상 절감액"과 연결), 통화/수수료 비교 표의 절제된 강조.

### 3. NerdWallet — 금융 비교·추천 · ★★★★
- 위치: Mobbin Web → "NerdWallet" 검색
- 왜: **"best for you"** 추천 카드 + 비교. 우리 결과(추천 1안 밀기, 현재↔추천 비교)와 랜딩의 "복잡한 선택을 대신 골라준다" 메시지에 부합.
- 참고할 것: 추천 배지·"왜 추천" 근거 노출, 비교 카드의 정보 위계.

### 4. 다나와 / 에누리 (한국 가격비교) — ★★★★
- 위치: Mobbin "Sites"/Web 또는 실제 사이트(danawa.com)
- 왜: 멘토가 지목한 **제품 비교 UI**. 공통 요소·차이점을 같은 기준 같은 행에 배열. 우리 결과 비교표의 정석.
- 참고할 것: 같은 항목 같은 행, 모노톤 + 차이값만 강조, 한국어 밀도.

### 5. Monarch Money — 예산·자산 관리 · ★★★★
- 위치: Mobbin Web → [Monarch](https://mobbin.com) "Monarch" 검색
- 왜: 숫자 중심의 **차분한 프리미엄 톤**. 브랜드색을 숫자에 남용하지 않는 절제(멘토 #11)의 좋은 본보기.
- 참고할 것: 타이포 위계, 여백, 카드·차트의 색 절제.

## 활용 가능 (유사도 ★★★★ ~ ★★★)

### 6. Copilot Money — 개인 재무 · ★★★
- 위치: Mobbin Web/iOS → "Copilot" 검색
- 왜: 미니멀·고급 마감. 랜딩과 대시보드의 여백·타이포가 우리 "절제" 방향과 맞는다.
- 참고할 것: 히어로 여백, 단일 액센트 사용.

### 7. Cleo (AI) — AI 머니 어시스턴트 · ★★★
- 위치: Mobbin iOS → "Cleo" 검색
- 왜: **대화형 AI로 절약을 안내**. 우리 "왜 나에게 추천됐나(AI 사유)"·추천 문장 칩(#4) 톤 참고.
- 참고할 것: 자유 입력 대신 추천 문장/선택지 먼저 주는 대화 UX.

### 8. The Zebra / Insurify — 보험 비교 · ★★★★(결과), ★★★(랜딩)
- 위치: Mobbin Web → "Insurify" 또는 "The Zebra" 검색
- 왜: **"비교하고 X 아끼세요"** — 여러 후보를 같은 기준으로 비교하고 하나를 추천. 우리 결과표와 랜딩 카피의 직접 참고.
- 참고할 것: 비교 히어로, 절감액 강조, 추천 1안 지정.

### 9. Google Flights — 항공 비교 · ★★★
- 위치: 실제 서비스 / Mobbin "Google" 검색
- 왜: **best/cheapest 배지**로 하나를 밀어주는 절제된 비교. 색·강조 최소화의 교과서.
- 참고할 것: 추천/최저 배지, 모노톤 표, 필터-결과 위계.

### 10. Trim / Bobby (구독 트래커) — ★★★
- 위치: Mobbin iOS → "Bobby" / "Rocket Money(구 Trim)" 검색
- 왜: **구독 목록·결제일 관리** UI. 우리 마이페이지의 구독/캘린더 관리 섹션과 라이트 3단계 구독 선택 참고.
- 참고할 것: 구독 카드·결제일 표시, 검색+멀티셀렉트 선택.

## 랜딩에 바로 적용할 3가지 (위 레퍼런스 종합)

1. **히어로 = 상대값 절감액.** (Rocket Money·Wise) 절대 총액 대신 "지금보다 월 ○○원 아껴요 / 또래 평균 대비" 를 크게.
2. **증거 + 리듬.** (Rocket Money) "X%가 절약", 지표 카드, 일러스트로 스크롤 리듬. 입력할수록 예상 절감액이 구체화됨을 예고.
3. **비교는 같은 기준 한 줄, 하나를 추천.** (다나와·NerdWallet·Zebra) 색 절제 + 추천 1안 배지.
