# 요고비 프론트 개발 기록

작업 단위의 기록이다. 커밋 이력은 Obsidian 노트의 "Git 변경 이력"에서 자동 생성하며, 이 문서는 왜·무엇을 바꿨는지를 남긴다.

## 2026-09-11 · 번들 프로토타입 → 정적 앱 재편성

**배경.** 원본 `yogo_v01.html`은 Base64 리소스 복원, Blob 스크립트, `new Function`, DC 템플릿 런타임을 묶은 약 4.15MiB 단일 배포 산출물이었고, 추천 금액을 브라우저의 고정 규칙(A/B/C, 12% 할인, 첫 OTT 무료)으로 계산했다. 작업 루트 원칙(금액 계산은 `BE_main`의 `pricing` 전담, 금액마다 출처, 미사용 혜택 0원, 필터·챗봇 동일 엔드포인트)과 어긋난다.

**한 일.**

- 프로토타입을 정적 HTML + DOM 이벤트 + JS 모듈로 교체. 원본 폰트·색·입력 단계·좌측 내비게이션·우측 지출 요약·카드 상세 구조를 보존.
- 브라우저 고정 계산(`combos()`, `CATALOG`, `55,000원` 강제 대체값)을 제거하고, 카탈로그·추천·계산·챗봇을 모두 `BE_main` API로 연결. 프론트는 숫자를 만들지 않는다.
- 공통 fetch 클라이언트(`src/api.js`)에 쿠키·CSRF·오류 보존·시간 제한·취소를 구현. 회원 요청만 `credentials: include`, 공개 요청은 인증 없이 호출.
- 입력 해석을 서버 식별자·enum·정수 GB로 정리(`src/model.js`). 원본 `num()`의 비정상 파싱(`-55000`→`55000`, `12.5`→`125`)을 명시적 정수 검증으로 대체.
- 결과는 서버 순서·개수·금액·출처를 그대로 표시하고 `missingInputs`·`warnings`를 숨기지 않음. CSV 내보내기는 수식형 문자열을 중화.
- 회원 화면(`account.html` + `src/account.js`): 이메일 확인 가입·재설정, 로그인·로그아웃·전체 종료, Google 연결, 세션 관리.
- 접근성·반응형 보강, `yogo_v01.html`은 `index.html`로 이동하는 리다이렉트만 남김.

**검증.** `npm test` 8개 계약·검증 통과. 실제 BE `bootJar` + 일회용 PostgreSQL + 개발 시드로 추천·인증·오류 대체·Chromium 화면 왕복 확인. 기록은 [연동 명세 §검증 기록](integration.md).

**남긴 경계.** 이미지 OCR·조합 저장·구독 저장·위약금 계산은 대응 BE API가 없어 미지원으로 두고, 버튼을 비활성 또는 "준비 중"으로 표시. 임의로 계약을 만들지 않는다.

## 2026-09-16 · 랜딩·결과 화면 리디자인 (Mobbin #1 Rocket Money 기준)

**배경.** 2차 멘토링과 [`refs/landing-references.md`](../refs/landing-references.md) 1번(Rocket Money)을 반영했다.
핵심은 UX_POLICY 1-①(결론 먼저·상대값 먼저)이다. 기존 랜딩 히어로는 "38세 곽두팔님, 월 38,000원 아끼셨네요"라는
가공 인물·가공 수치였고, 지표 4칸(1,200+/50+/₩34,000/96%)도 출처가 없었다. ux-flow A9-①이 금지한 단정 카피다.

**한 일.**

- 랜딩 히어로를 절감액 중심으로 교체. 폰 목업이 절감액을 가장 큰 숫자로 두고 총액은 보조 행으로 내렸다.
  또래 평균 비교 줄은 **A9-① 사인오프 전까지 '예시 화면' 안에서만** 쓰며 `ponytail:` 주석으로 표시했다.
- 지표 4칸에서 출처 없는 수치를 걷어냈다. 앞 2칸은 `GET /catalog/plans`·`/catalog/services`의 실제 개수를
  `landing.js`가 채우고, 못 받으면 카드를 숨긴다(`.stats`는 `auto-fit`이라 빈칸이 남지 않는다).
  구독 수는 등급 없는 서비스를 빼서 `loadCatalog()`가 실제로 고르게 해주는 개수와 맞춘다.
  뒤 2칸은 검증 가능한 제품 사실로 바꿨다(질문 3개 / 금액 전부에 출처).
- 신뢰 칩을 랜딩·결과에 넣었다. "Bank-level encryption" 자리에 우리가 실제로 지키는 것만 적는다 —
  카드·계좌 미연결, 금액마다 출처, 미사용 혜택 0원(절대 원칙 1·4).
- 결과 화면: 초록 한 줄이던 `.headline`을 절감액 히어로 카드로 교체(월 절감액이 가장 큰 숫자, 연 환산과
  현재↔추천 델타 칩을 함께). 비교 3열은 `<colgroup>` + `table-layout: fixed`로 **가로 27% 균일**,
  머리 셀의 각 줄에 `min-height`를 줘 총액 3개가 같은 선에 놓이게 했다(세로 균일).
- 문장 단위 줄바꿈: `splitLines()`(model.js)를 추가해 부가혜택·할인은 항목마다 한 줄,
  약정/종료일은 두 줄, 추천 사유·안내는 문장마다 한 줄로 그린다. 공백 없는 마침표는 자르지 않아
  `2026-11-30`·`1.5GB`·`₩4,900`이 쪼개지지 않는다. 한국어 줄바꿈은 `word-break: keep-all`로 통일.

**검증.** `npm test` 11개 전부 통과. `splitLines` 계약 테스트를 추가했다.
같은 날 죽은 테스트(`tests/redesign.test.js`)도 정리했다 — 삭제된 `src/recommend-mock.js`·`CATALOG`를
import해 파일째 실패하고 있었다. 살아 있는 두 건(통신사 매핑, 구간 대표값)은 전부 BE 계약 검증이라
`tests/contract.test.js`로 옮기고 파일을 지웠다. 프론트가 금액을 만들던 시절의 목업 검증은 되살리지 않는다(절대 원칙 2).
레이아웃은 BE 없는 더미 데이터로 확인했고, 배포 후 `yogob.fly.dev`에서 지표가 실제 카탈로그 수
(요금제 1,711 / 구독 6)로 채워지는 것까지 확인했다.

**남긴 것.**

- 또래 평균 비교 카피는 출처 확보(ux-flow A9-①) 전까지 예시 화면 밖으로 내보내지 않는다.
- 커밋 `51a1b9b`은 메시지가 인증(D-22) 작업만 설명하지만 diff에는 이 화면 작업도 함께 들어가 있다.
  이미 푸시된 뒤라 이력을 고치지 않고 이 기록으로 남긴다.

## 2026-09-16 · 프론트에서 금액 계산 제거 · 또래 평균 카피 삭제

**배경.** 절대 원칙 2는 금액 계산을 `BE_main`의 `pricing` 전담으로 둔다. `integration.md`도
"현재 통신비는 화면의 메모다. 추천에 전달하거나 **절감액 계산에 쓰지 않는다**",
"`baseline`은 정가 합계이며 **현재 사용자의 청구액으로 표현하지 않는다**"고 못박는다.
같은 날 넣은 절감액 히어로가 둘 다 어기고 있었다 — 프론트가 `현재 − 추천`으로 절감액을 만들고,
그 값을 "이 조합으로 바꾸면 매달"이라고 현재 청구액 기준처럼 적었다.

**한 일.**

- 절감액 히어로를 BE 값만 쓰도록 되돌렸다. 월은 `monthlySavings`, 연은 `annualSavings`,
  라벨은 "정가 대비 매달". 델타 칩도 `monthlyTotal`·`baseline` 두 서버 값으로 바꿨다.
  사용자의 현재 지출은 표의 '현재' 열(입력값 합계)에만 남는다.
- 기간 탭(1·6·12개월)을 없앴다. BE가 주는 기간은 월과 연뿐이라 6·12개월 금액은 프론트 곱셈으로만
  존재하던 값이었다. 필요해지면 계약 변경을 먼저 제안한다(임의로 만들지 않는다).
- 회귀 방지 테스트를 넣었다 — `src/*.js`에서 `monthlyTotal|baseline|monthlySavings|annualSavings`에
  산술 연산자가 붙으면 파일·줄 번호와 함께 실패한다. 곱셈을 되살려 실제로 실패하는 것까지 확인했다.
- 남긴 경계: 사용자 입력의 단순 합계(`currentTotal`, 라이트 요약, app.js 예산 비교)는 유지한다.
  `integration.md`가 "화면의 메모"로 명시 허용하며 서버로 보내지 않는다. 다만 절감액 계산에는 쓰지 않는다.
- 또래 평균 비교(게이지 + "비슷한 사용량인 사람보다 월 12,000원 적게")를 랜딩에서 삭제했다.
  ux-flow A9-① 사인오프를 못 받았고, 출처 없는 상대 수치를 예시로라도 두지 않는다.
  폰 목업도 '현재 대비'가 아니라 결과 화면과 같은 **정가 대비**로 맞췄다 — 랜딩이 제품이
  계산하지 않는 기준을 약속하지 않게 한다.
- 결과 화면의 정보 제보를 `<details>` 토글("정보가 잘못되었나요?") 하나로 접었다.
  기본 화면에서 폼이 통째로 보이던 것을 줄인다. 네이티브 요소라 스크립트를 더하지 않는다.

**검증.** `npm test` 12개 전부 통과. 더미 데이터로 결과·랜딩 렌더링 확인.

- 운영 배포용 정적 서버 프록시(`/api`·`/oauth2`·`/login/oauth2`) 또는 같은 사이트 BE 오리진 구성. 현재 Spring 보안 설정은 새 JS/CSS 경로를 허용하지 않는다.

## 2026-09-17 · 회원 화면 실사용 점검 — Google 관련 구멍과 되살아난 위반

**배경.** React 전환 뒤 회원 화면(`/results`·`/calendar`·`/mypage`)이 로그인 상태로 그려지는 걸
한 번도 본 적이 없었다. 배포본에 실제로 로그인해 돌려 보고 나온 것들이다.

**Google 로그인 복귀가 끊겨 있었다.** BE `GoogleLogin` 은 로그인 뒤 `AUTH_RETURN_URL` +
`#auth=success|failed|account-conflict` 로 돌려보낸다. 옛 `header-auth.js` 가 이걸 받았는데 전환 중
유실됐고, `src/` 어디에도 `#auth=` 를 보는 코드가 없었다. 게이트에서 "Google 로 계속하기" 를 누른
사람이 랜딩에 멈춰 D-36 의 "입력값은 유지해 로그인 후 같은 자리에서 이어지게 한다" 가 깨져 있었다.
`AuthReturn.jsx` 로 되살렸다 — `yogobi:next`(허용 목록 검사)로 복귀하고, success 인데 `/me` 가 비면
로그인된 척하지 않고 쿠키 차단을 안내한다.

**Google 캘린더 담기 구멍 3개.**

- 링크의 `details` 는 **질의문자열로 구글 서버에 전달된다.** 거기에 현재·전환 월 요금과 절감액이
  실려 있었다 — 개인정보처리방침 4조("외부에 제공하지 않습니다")와 어긋난다. 금액을 빼고, 금액까지
  담으려면 기기 안에서 끝나는 `.ics` 를 받도록 화면에 적었다. 테스트로 묶었다.
- ICS `UID` 에 기준일이 박혀 있어 약정 만료일을 고쳐 다시 받으면 옛 일정이 남고 새로 쌓였다.
  단계 번호만 쓰게 해 재가져오기가 '추가' 가 아니라 '이동' 이 되도록 했다.
- `.ics` 내려받기가 문서에 붙지 않은 `<a>` 를 클릭하고 그 자리에서 `revokeObjectURL` 을 불렀다.
  파이어폭스는 클릭을 안 받고 사파리는 다 쓰기 전에 URL 이 끊긴다.

**금액 계산 금지 테스트가 눈이 멀어 있었다.** `readdirSync('src').filter(f => f.endsWith('.js'))` 로
최상위만 훑는데 전환으로 로직은 `src/lib/`, 화면은 `.jsx` 로 옮겨가 **훑는 파일이 0개**였다. 그 사이
`/mypage` 에 위반 2건이 되살아나 있었다 — 내 구독 "월 {합계}", 중복 결제 점검 "월 {합계} · 1년
{합계 × 12}". 재귀 + `.jsx` 로 고치고, 훑은 파일이 10개 미만이면 테스트가 스스로 실패하게 했다.
테일윈드 클래스(`items-baseline`, `gap-3`)를 코드로 오해하지 않도록 `(?<![\w-])` 를 붙였다.
위반 2건은 건수 표시로 바꿨다 — 합계가 필요하면 BE 가 내려주는 게 맞다.

**회원 탈퇴 화면이 아예 없었다.** 개인정보처리방침 3·6조가 약속하고 BE 도 `DELETE /api/v1/me` 를
여는데 프론트에 길이 없었다. `/mypage` 하단에 넣었다. 되돌릴 수 없어 '탈퇴' 를 직접 적게 하고
(`confirm()` 대화상자는 쓰지 않는다) 성공 시 `/me` 캐시와 `sessionStorage` 를 비운다.

**화면을 돌려 보고 추가로 나온 것 4개.**

- **"정보가 잘못되었나요?" 제보 토글이 통째로 빠져 있었다.** BE 는 `POST /api/v1/catalog/reports` 를
  그대로 열어 두고 있어 받는 쪽은 멀쩡했다. 되살렸다.
- 되살린 제보가 **CSRF 없이 나가 전부 403** 이었다. BE `SecurityConfig` 는 `/recommendations`·
  `/calculator`· `/chat/messages` 만 CSRF 를 면제하는데 `/catalog/reports` 는 목록에 없다.
  `member: true` 로 고치고, 면제 경로가 아닌 POST/DELETE 가 토큰 없이 나가면 실패하는 테스트를 넣었다.
  수정을 되돌려 실제로 빨간불이 뜨는지 확인했다.
- `/results`·`/calendar`·`/mypage` 에 **푸터가 없어 이용약관·개인정보처리방침에 닿을 길이 없었다.**
  결과 화면을 바로 열면 방침 링크가 화면 어디에도 없다. 세 화면에 붙였다.
- `--color-muted` 가 `#8a8b9e` 로 **흰 배경 대비 3.35:1** 이었다(WCAG AA 최소 4.5:1). 본문 보조
  문구 대부분이 이 토큰을 쓴다. `#6e6f85`(4.91:1)로 낮췄고 배포본에서 다시 재 확인했다.

**BE 쪽으로 넘길 것 2개(여기서 고치지 않았다).**

- **중복 결제 탐지가 실제로는 안 잡힌다.** `DuplicateDetector.benefitOverlaps` 가
  `benefitType == FREE` 만 보는데 실제 카탈로그는 `BUNDLE_INCLUDED` 로 들어 있다. 운영에서 확인:
  요금제 159(`KT 초이스 더블 유튜브 프리미엄+넷플릭스`, 넷플릭스가 `BUNDLE_INCLUDED`)를 현재
  요금제로 두고 넷플릭스를 구독으로 등록했는데 `/me/detections` 가 빈 배열이다. 코드에 한계를
  적어 둔 `ponytail:` 주석이 이미 있지만, 실제 데이터에서는 규칙이 사실상 한 번도 안 걸린다.
